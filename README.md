# Circle Turtle Animation

A simple Python animation project created using the Turtle graphics module.

## Features

* Creates a circular pattern using multiple circles
* Uses different colors
* Rotates the turtle after each circle
* Simple and beginner-friendly Python project

## Technologies Used

* Python
* Turtle Graphics

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed on your system.
3. Run the following command:

python circle_animation.py

## Output

The program opens a Turtle graphics window and creates a colorful circular pattern.
